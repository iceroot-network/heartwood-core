# Heartwood Core

Heartwood Core is the Rust node for the IceRoot network.

Heartwood Core is a new implementation in Rust. Its protocol design inherits from ARK Core and
Solar Core; Solar Core serves as the reference implementation for compatibility tests.

The project is at an early stage. Work starts with the test tooling: a reference oracle built from
Solar Core, and a differential-test harness that the node's crates will be checked against.
